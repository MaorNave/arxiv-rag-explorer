# ---------------------------------------------------------------------------
# arXiv RAG Explorer - Python dependencies
#
#   pip install -r requirements.txt
#   python main.py
#
# That is the whole installation. Everything that is not a Python package is set up
# by the app itself on its first run, inside the project's storage/ folder:
#   * Ollama: the running one is used if present; otherwise the app downloads its own
#     copy (storage/runtime) and runs it while the app runs,
#   * the Qwen 3.5 chat model and the embedding model (pulled through Ollama),
#   * the small cross-encoder reranker (Hugging Face),
#   * on Macs with >= 16 GB: a local FLUX.2 image model.
# Optional: `python -m rag_app.setup_models` downloads Ollama, the models and the reranker up front.
# ---------------------------------------------------------------------------
