#   * explicitly with `python -m rag_app.setup_models`, or
#   * by the one-shot installer: scripts/setup.sh (macOS/Linux) / scripts/setup.ps1 (Windows).
# The only system prerequisite is Ollama itself: https://ollama.com/download
